# Visual Stochastic Calculus

An interactive, visual introduction to stochastic calculus: Brownian motion, the Itô integral,
Itô's lemma, stochastic differential equations and their applications, all the way to the
diffusion models behind AI image generators. Every idea comes with a simulation you can play with,
a plain-language explanation of each formula, a "predict first" question, a precise statement with
references, and a short Python version you can run yourself.

**Live site:** https://nnm-psd.github.io/visual_stochastic_calculus/

## Chapters

1. **Brownian Motion:** a jittering particle, random walk → Brownian motion, defining properties, rough paths
2. **Variation & Martingales:** quadratic variation, martingales, the reflection principle
3. **The Itô Integral:** why the evaluation point matters, trading gains, the Itô isometry
4. **Itô's Lemma:** the surviving second-order term, the lemma in action, Itô vs Stratonovich, correlated Brownian motions
5. **Stochastic Differential Equations:** Euler–Maruyama, GBM / OU / CIR, Fokker–Planck
6. **Applications:** Black–Scholes by hedging, Girsanov, Feynman–Kac
7. **Diffusion Models:** data to noise, the score, the reverse-time SDE, Langevin sampling
8. **Beyond Brownian Motion:** jumps and fat tails, the Kalman–Bucy filter

Every Python program on the site can be edited and run in the browser (Pyodide: Python and NumPy compiled to
WebAssembly), and an unedited run reproduces the published output.

Every chapter ends with a short recap quiz and can be downloaded as a PDF (`pdf/`). Progress (sections whose
prediction you answered and whose chart you tried) is kept in your browser and shown on the home page.

## Run locally

It is a static site with no build step and no dependencies to install. Open `index.html` in a browser.
KaTeX loads from a CDN.

## Layout

- `index.html`, plus one folder per chapter, each with its own `index.html`
- `assets/js/engine.js`: shared helpers (seeded RNG, Brownian paths, canvas and chart helpers, "predict first")
- `assets/js/*.js`: one script per interactive section
- `notation/index.html`: generated by `python tools/build_notation.py` from the chapter glossaries (re-run after editing one)
- `ARCHITECTURE.md`: design notes, the section template and conventions

## Checks

Every push runs `.github/workflows/checks.yml`, which you can also run locally:

- `python tools/check_snippets.py` runs all Python snippets and confirms they still print their published output (`--update` rewrites the outputs after an intentional change).
- `python tools/check_pages.py` loads every page in headless Chrome and fails on console errors, unrendered math or broken links.
- `python tools/build_notation.py` regenerates the notation page. CI fails if it is out of date.
- `python tools/build_pdfs.py` re-exports the chapter PDFs in `pdf/` (not run in CI; re-run after editing a chapter).
