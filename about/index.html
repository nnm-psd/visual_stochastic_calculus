About this site

A free, interactive introduction to stochastic calculus, from a jittering particle to the diffusion models behind AI image generators. Every idea has a simulation you can play with.

What it is

Eleven chapters and 36 sections, plus 30 interview questions. Every section is built the same way: a short explanation, a "Predict first" question, one formula with every symbol explained in plain words, an interactive simulation, a precise statement with references, and a short Python program you can edit and run in the browser. Each chapter ends with a recap quiz and can be downloaded as a PDF.

It is written for readers with high-school algebra and no probability background. The "Going deeper" panels are there for readers who want the exact theorems.

Who made it

Created by Ngoc Minh Nguyen (github.com/nnm-psd). Built with the help of Claude (Anthropic). Every result on the site is checked by automated tests, described below.

How the content is checked

  • Every Python program is re-run on every change. Its output must still match the "Output when we ran it" shown on the page, to the last printed digit. You can check this yourself: an unedited program run in the browser reports "Matches the published output".
  • Every page is loaded in a real browser on every change. The check fails on any script error, on formulas that did not render, and on broken links.
  • The numbers under each chart are compared with theory. Each stats line prints the simulated value next to the exact one.
  • References were checked against the sources: textbook section numbers against published tables of contents, and journal citations against publisher records.

The checks are public: see the latest runs.

Privacy

No cookies, no tracking, no accounts. Your theme choice and your progress are stored only in your own browser, and "Reset progress" on the home page erases them. Pressing "Run in browser" downloads Python from the jsDelivr CDN. The formula fonts also load from it.

Acknowledgements

The layout follows Seeing Theory (Brown University), and the particle simulation is inspired by MinuteLabs. Formulas are rendered by KaTeX, and the in-browser Python is Pyodide. The mathematics follows the textbooks and papers cited in each section, especially Shreve's Stochastic Calculus for Finance II, Øksendal's Stochastic Differential Equations, and Mörters & Peres's Brownian Motion.
